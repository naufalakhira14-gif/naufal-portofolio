MACHINE LEARNING · CRIME PATTERN ANALYSIS

Bangladesh Crime Pattern Analysis

Proyek ini menganalisis pola kriminalitas di Bangladesh menggunakan Exploratory Data Analysis (EDA) dan K-Means Clustering. Analisis mengeksplorasi karakteristik waktu kejadian, lokasi, cuaca, demografi, dan infrastruktur publik untuk memahami pola dalam dataset.

Python Pandas NumPy Scikit-learn K-Means PCA

01 / PROJECT OVERVIEW

Project Overview

Proyek ini mengeksplorasi pola kriminalitas di Bangladesh berdasarkan informasi kejadian, lokasi, waktu, kondisi cuaca, demografi penduduk, dan infrastruktur publik. Exploratory Data Analysis digunakan untuk memahami distribusi data, sedangkan K-Means Clustering digunakan untuk mengelompokkan observasi berdasarkan kemiripan karakteristiknya.

DATASET SOURCE

Bangladesh Crime Dataset

Dataset yang digunakan untuk analisis pola kriminalitas dan clustering.

02 / OBJECTIVE

Project Objective

Crime Pattern Analysis

Mengidentifikasi distribusi kejahatan berdasarkan kategori, waktu kejadian, dan lokasi.

Data Preparation

Melakukan data quality assessment, cleaning, categorical encoding, dan feature scaling sebelum clustering.

Clustering & Evaluation

Menggunakan K-Means, Elbow Method, dan Silhouette Score untuk mengeksplorasi serta mengevaluasi kelompok data.

05 / MODEL APPROACH

K-Means Clustering

01. Feature Preparation

Data kategorikal di-encode dan fitur dipersiapkan untuk merepresentasikan karakteristik observasi.

02. Feature Scaling

Feature scaling diterapkan sebelum clustering agar perbedaan skala fitur lebih terkendali.

03. Cluster Evaluation

Elbow Method dan Silhouette Score digunakan untuk mengevaluasi kandidat jumlah cluster.

04. Cluster Profiling

Karakteristik setiap cluster dibandingkan untuk mengeksplorasi perbedaan profil demografi, infrastruktur, dan kategori kejahatan.

Setelah preprocessing dan categorical encoding, dataset menghasilkan 101 kolom fitur sebelum proses clustering. K-Means digunakan untuk membentuk empat cluster, kemudian PCA digunakan untuk memvisualisasikan hasil clustering dalam dua dimensi.
