Credit Score Prediction

Project mencakup data cleaning, exploratory data analysis, preprocessing, model comparison, hyperparameter tuning, model evaluation, hingga deployment.

02 / OBJECTIVE

Project Objective

Membangun model multiclass classification untuk memprediksi kategori credit score pelanggan.

01

Poor

Kategori credit score dengan kondisi kredit yang relatif rendah.

02

Kategori credit score dengan kondisi kredit pada tingkat standar.

03

Good

Kategori credit score dengan kondisi kredit yang relatif baik.

05 / MODEL COMPARISON

Classification Model Comparison

Four classification models were evaluated to determine the most suitable model for predicting customer credit score categories.

Model Accuracy
Logistic Regression 63.02%
Decision Tree 62.52%
Random Forest 71.78%
XGBoost 70.40%

Random Forest selected as the best base model with an accuracy of 71.78%.

11 / KEY FINDINGS

Project Results

01

Random Forest achieved the best performance among four evaluated models.

02

Hyperparameter tuning improved Random Forest accuracy from 71.78% to 72.02%.

03

Outstanding_Debt was the most influential feature according to Random Forest feature importance.

04

Standard was the easiest class for the model to identify, while Good had the lowest F1-score.

05

The final model achieved a weighted F1-score of 71.95%.
