01 / PROJECT OVERVIEW

Project Overview

Project ini merupakan end-to-end machine learning project untuk memprediksi status placement mahasiswa dan estimasi salary setelah lulus berdasarkan faktor akademik, skill, pengalaman, dan faktor personal.

02 / OBJECTIVE

Project Objective

Placement Prediction

Memprediksi apakah seorang mahasiswa berhasil mendapatkan placement setelah lulus.

Salary Prediction

Memprediksi estimasi salary mahasiswa berdasarkan karakteristik dan pengalaman yang tersedia.

Model Optimization

Membandingkan beberapa model machine learning, melakukan hyperparameter tuning, dan melakukan deployment.

03 / DATASET

Dataset

5,000 Students

Student records yang digunakan dalam project.

25 Columns

Atribut akademik, skill, pengalaman, personal, placement, dan salary.

Student Placement & Salary Dataset

Dataset digunakan untuk membangun dua task machine learning: classification dan regression.

07 / KEY FINDINGS

Key Findings

01

Academic performance dan pengalaman praktis berhubungan dengan career outcomes mahasiswa.

02

Logistic Regression menjadi model terbaik untuk placement prediction dengan F1-Score sebesar 0.9405.

03

ElasticNet menjadi model terbaik untuk salary prediction dengan nilai R² sebesar 0.598.

04

Hyperparameter tuning dilakukan menggunakan Optuna untuk membantu mendapatkan konfigurasi model yang lebih optimal.
