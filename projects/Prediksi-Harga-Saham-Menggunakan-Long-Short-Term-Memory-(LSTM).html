MACHINE LEARNING · TIME SERIES

Stock Price Prediction

Project ini membangun model Long Short-Term Memory (LSTM) untuk memprediksi harga penutupan saham berdasarkan data historis. Dua dataset saham, GOOGL dan INTC, digunakan untuk membangun Baseline LSTM dan Improved LSTM serta membandingkan performanya.

Python TensorFlow Keras LSTM Time Series

01 / PROJECT OVERVIEW

Project Overview

Project ini berfokus pada penerapan Long Short-Term Memory (LSTM) untuk melakukan time series forecasting pada harga saham. Data historis GOOGL dan INTC digunakan untuk memprediksi Closing Price pada hari perdagangan berikutnya berdasarkan lima hari perdagangan sebelumnya.

DATASET SOURCE

GOOGL & INTC Stock Historical Data

Dataset historis harga saham Alphabet Inc. (GOOGL) dan Intel Corporation (INTC) yang digunakan untuk membangun dan mengevaluasi model LSTM time series forecasting.

View Dataset

02 / OBJECTIVE

Project Objective

Memprediksi harga Closing Price pada hari berikutnya berdasarkan lima hari perdagangan sebelumnya serta membandingkan performa Baseline LSTM dan Improved LSTM pada dua dataset saham yang berbeda.

03 / DATASET

Dataset

Data historis saham Alphabet Inc.

10,098 INTC Trading Records

Closing Price.

08 / KEY FINDINGS

Key Findings

01

Improved LSTM memberikan peningkatan performa yang signifikan pada dataset GOOGL, dengan RMSE turun dari 63.69 menjadi 30.29.

02

Pada dataset INTC, Baseline LSTM justru menghasilkan performa yang lebih baik dibandingkan Improved LSTM.

03

Model dengan arsitektur yang lebih kompleks tidak selalu menghasilkan performa forecasting yang lebih baik.

04

Arsitektur LSTM yang optimal bergantung pada karakteristik dataset dan pola time series yang digunakan.
