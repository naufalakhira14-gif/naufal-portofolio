MACHINE LEARNING · MUSIC RECOMMENDATION

Song Recommendation System

Proyek ini membangun sistem rekomendasi lagu berbasis Machine Learning yang menyarankan lagu berdasarkan kemiripan karakteristik audio. Fitur seperti Danceability, Energy, Valence, Acousticness, dan Tempo digunakan untuk menemukan lagu dengan karakteristik musikal serupa.

Python Pandas NumPy Scikit-learn Cosine Similarity

01 / PROJECT OVERVIEW

Project Overview

Proyek ini mengembangkan sistem rekomendasi lagu menggunakan pendekatan Content-Based Recommendation. Sistem membandingkan karakteristik audio antar lagu untuk memberikan rekomendasi berdasarkan kemiripan fitur, bukan hanya berdasarkan popularitas lagu.

DATASET SOURCE

05 / MODEL APPROACH

Content-Based Recommendation

01. Feature Selection

Menggunakan 12 fitur numerik yang merepresentasikan karakteristik audio lagu.

02. Feature Scaling

StandardScaler digunakan untuk menstandarkan skala fitur audio sebelum perhitungan similarity.

03. Similarity Measurement

Cosine Similarity digunakan untuk mengukur kemiripan vektor fitur audio antar lagu.

04. Recommendation Function

Fungsi recommend_song() menghasilkan rekomendasi lagu serupa berdasarkan input lagu.

07 / KEY FINDINGS

Key Findings

01

Karakteristik audio digunakan untuk merepresentasikan kemiripan musikal antar lagu.

02

Standardisasi fitur dilakukan sebelum menghitung similarity agar perbedaan skala fitur lebih terkendali.

03

Cosine Similarity digunakan untuk menentukan lagu dengan karakteristik audio yang paling mirip.

04

Sistem berfokus pada kemiripan audio, bukan hanya popularitas lagu.
